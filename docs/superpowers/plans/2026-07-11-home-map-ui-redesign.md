# 首页地图 UI 重构实施计划

1. 用 UI 测试锁定新 HUD、单一工具入口和展开菜单，移除旧“地图操作”断言。
2. 为 MapTheme 增加可测试的地图视觉参数，修正暗色主题标注与纹理强度。
3. 重构 ChinaMapView 的背景、地区底层、边界和文字绘制。
4. 重构 HomeMapHud、删除 HomeCommandBar，并把 MapFab 改成带进度环的向上展开工具栈。
5. 调整顶部/底部渐隐与上下文面板位置，保证所有浮层互斥。
6. 运行 shared 与 Android 单测，安装到模拟器。
7. 采集首页 before/after、悬浮球展开、地区面板、1.5 字体和至少两个主题截图。
