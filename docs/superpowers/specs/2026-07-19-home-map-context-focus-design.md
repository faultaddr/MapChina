# MapChina 主页清新化、上下文聚焦与极光悬浮球设计

日期：2026-07-19
状态：已确认
适用平台：Android、iOS（Compose Multiplatform）

## 1. 背景

当前主页已经以全屏地图为主体，并具备轻量标题、区域卡片、地图工具悬浮入口和全国到省市区的钻取能力，但仍存在三类体验缺口：

1. 默认主页的视觉语言偏功能化，缺少清新、细腻、统一的质感。
2. 单击区域只触发高亮和卡片；真正的居中放大需要双击或点击卡片按钮。进入下一级后，省市区图层之间的关系不够直观，容易产生“只展示当前省市地图”的割裂感。
3. 悬浮入口是普通实色按钮，和地图主题的细腻感不匹配。

本设计将三项改动作为一条连续体验处理：清新的地图首页负责建立氛围，单击聚焦负责保持空间连续性，极光悬浮球负责承载低频工具。

## 2. 目标

- 默认主页采用“晨雾青瓷”视觉方向：暖白、薄荷青、低饱和地图和轻量 HUD。
- 单击任意可交互区域后，立即高亮，随后用 650ms 动画移动到可见地图区域中央并放大。
- 聚焦和钻取过程中始终保留全国省界作为淡化的空间上下文。
- 镜头稳定后再显示区域卡片，避免卡片与地图争抢注意力。
- 进入市级或区级地图时，把子区域作为当前图层叠加，而不是替换全国上下文。
- 悬浮球使用慢速、克制的极光渐变跑马灯，并在不适合持续运动时暂停。
- Android 和 iOS 共享一致的交互语义，并以真实模拟器运行结果验收。

## 3. 非目标

- 不改变足迹等级、覆盖率或区域数据模型。
- 不重做区域卡片的信息结构和足迹标记流程。
- 不删除现有地图主题；“晨雾青瓷”用于刷新默认主题，其他主题继续保留各自风格。
- 不引入新的地图 SDK、图片快照背景或远程视觉资源。
- 不把单击直接改成无卡片的自动钻取；进入下一级仍由区域卡片中的明确动作触发。

## 4. 已确认的体验方向

### 4.1 默认主页：晨雾青瓷

- 页面背景使用暖白到薄荷青的低对比渐变。
- 地图保持页面视觉主体，纹理和装饰只提供细微层次。
- 顶部标题、点亮进度和“足迹 / 全国”控制保持轻量，不形成独立的厚重仪表盘卡片。
- 默认地图边界采用低饱和青绿色；已点亮区域提高色彩密度，但不使用刺眼高亮。
- 底部导航和地图工具使用半透明暖白表面、细边框与柔和阴影。

### 4.2 单击聚焦时序

一次完整交互按以下顺序执行：

1. 用户单击区域。
2. 立即触发轻量触觉反馈。
3. 关闭旧区域卡片并高亮新区域。
4. 根据区域边界、安全区和当前画布尺寸计算镜头目标。
5. 用 650ms 的平滑缓入缓出动画把区域移动到可见地图区域中央并放大。
6. 动画期间，全国上下文层保持可见；非选中区域的显示透明度系数降为 0.25。
7. 镜头动画完成后，区域卡片从底部轻柔进入。

“可见地图区域”不等同于物理屏幕中心。镜头计算需要扣除顶部 HUD、底部导航和区域卡片预留空间，使区域在最终稳定状态下不被界面遮挡。

### 4.3 钻取与返回

- 点击区域卡片中的“查看市级地图”或“查看区级地图”后，当前区域的子边界以淡入方式叠加。
- 全国省界作为上下文层继续绘制，并保持较低透明度。
- 上下文层只参与绘制，不参与当前层级的点击命中。
- 返回上级时，子区域层淡出，镜头平滑缩远；全国上下文层始终不闪烁、不消失。
- 回到全国层级后，省界恢复正常样式和点击能力。

### 4.4 极光呼吸悬浮球

- 主悬浮球使用青、蓝、淡紫组成的环形渐变。
- 渐变边缘每 7000ms 完成一圈，外层使用低透明度慢速呼吸光晕。
- 悬浮球内部保持暖白玻璃质感，图标使用默认主题主色。
- 工具菜单展开时暂停环形动画，避免多个焦点同时运动。
- 悬浮球不可见、页面离开前台或系统启用“减少动态效果”时停止动画。
- 动画停止时保留静态极光渐变，不退化成普通实色按钮。

## 5. 技术设计

### 5.1 地图图层角色

`RenderState.kt` 中的区域边界需要具备明确的图层角色：

- `CONTEXT`：全国省界背景，低透明度、不可点击。
- `ACTIVE`：当前层级的省、市或区边界，正常样式、参与点击。

`OverlayData` 保存图层角色和显示透明度系数。`MapController` 提供按角色添加、更新和清理边界的接口，避免 `MapViewModel` 继续通过“混在一个集合后再移除命中区域”的隐式规则维护层级。

在全国层级，省界属于 `ACTIVE`。进入省、市或区层级后，同一份省界缓存切换为 `CONTEXT`，当前子边界作为 `ACTIVE` 叠加。

### 5.2 绘制顺序

`ChinaMapView.kt` 按固定顺序绘制：

1. 晨雾青瓷背景与轻纹理。
2. 邻国轮廓。
3. `CONTEXT` 全国省界。
4. `ACTIVE` 当前区域边界。
5. 选中区域高亮和脉冲效果。
6. 足迹路线、景点、照片与其他标记。
7. 当前层级标签。

`GeoPathCache` 继续缓存解析后的路径。上下文层淡化只改变绘制参数，不重新解析 GeoJSON。点击命中索引只由 `ACTIVE` 图层生成。

### 5.3 聚焦状态

`MapViewModel.kt` 增加可测试的区域聚焦状态：

- `Idle`
- `Animating(regionId)`
- `Focused(regionId)`

`focusRegion(regionId)` 负责：

1. 校验区域存在。
2. 更新选中区域和高亮状态。
3. 清除旧面板。
4. 请求带安全区的镜头动画。
5. 仅在当前动画仍然有效时转入 `Focused`。
6. 由 `Focused` 状态驱动区域卡片显示。

如果用户在动画完成前点击另一个区域，旧请求被取消，新的 `regionId` 成为唯一有效请求。旧动画的完成回调不得显示旧区域卡片。

`MapScreen.kt` 只把地图点击转交给 `focusRegion`，并根据聚焦状态显示卡片，不再分别编排高亮、选择和卡片时序。

### 5.4 镜头目标与动画

`ViewportState.kt` 增加带可见区域安全边距的边界适配计算。输入包括：

- 区域地理边界。
- 画布宽高。
- 顶部、底部和左右安全边距。
- 目标填充比例。

输出仍为中心经度、中心纬度和缩放级别。计算必须同时满足横向和墨卡托纬度跨度约束。

`MapController.kt` 的镜头动画需要：

- 使用 650ms 的平滑缓入缓出曲线。
- 为每次动画生成单调递增的请求标识。
- 新请求开始时取消旧动画。
- 只通知最新请求完成。
- 在动画取消、页面销毁或导航离开时清理回调。

### 5.5 默认主题与 HUD

- `MapTheme.DEFAULT` 更新为晨雾青瓷色板。
- `HomeMapTitle.kt` 继续保持无厚重卡片的 HUD 结构，调整文字层级、间距、透明度和进度表现。
- `MapScreen.kt` 的顶部与底部渐变遮罩使用同一组主题色，避免地图和系统 UI 之间出现硬边。
- 其他主题仍通过 `MapTheme.visualStyle` 提供自身颜色，不被默认主题强制覆盖。

### 5.6 悬浮球实现

`MapFab.kt` 使用 Compose Multiplatform 可用的绘制与动画 API：

- `rememberInfiniteTransition` 驱动 0 到 360 度的慢速角度变化。
- 环形渐变通过 `Brush.sweepGradient` 在悬浮球自己的绘制层完成。
- 呼吸光晕使用低幅度透明度和缩放变化，不改变按钮点击区域。
- `isExpanded`、组件可见性和系统动态效果设置共同决定动画是否运行。
- 保留现有语义标签、最小点击尺寸、触觉反馈和工具菜单内容。

## 6. 加载、失败与取消

### 6.1 子区域加载

进入下一级后，在子边界准备完成前继续显示全国上下文层和选中区域，并显示轻量“正在展开市级地图”或“正在展开区级地图”提示。

只有数据与边界都可用时，`ACTIVE` 子区域层才整体切换。加载过程不能先清空当前边界，从而避免空白画布。

### 6.2 加载失败

- 保留当前地图、镜头和区域卡片。
- 不提交新的层级路径和当前层级状态。
- 显示简短失败提示和重试入口。
- 重试沿用同一区域，不重复追加导航路径。

### 6.3 缺少空间数据

- 有边界：按边界和安全区计算镜头目标。
- 无边界但有中心点：使用中心点和按行政级别预设的缩放。
- 边界与中心点都缺失：保留当前镜头，高亮区域并显示卡片，不进入永久 `Animating` 状态。

### 6.4 生命周期与快速操作

- 快速连续点击遵循“最后一次点击优先”。
- 返回上级、回到全国、切换底部页面或控制器离开组合树时取消在途动画。
- 取消后的完成回调不得改变聚焦状态、当前路径或卡片。

## 7. 无障碍与动态效果

- 悬浮球、地图工具、返回按钮和区域卡片保留清晰的语义描述。
- 所有悬浮入口保持至少 44dp 的点击尺寸。
- 文字放大时工具菜单继续容纳长标签。
- 系统减少动态效果开启时：
  - 镜头使用短时淡变或直接定位。
  - 图层仅做短时透明度切换。
  - 极光环使用静态渐变。
- 颜色对比不能只依赖渐变光效；图标、边界和文字必须独立可辨识。

## 8. 性能要求

- 全国边界继续使用现有 `provinceBoundaryCache`。
- 图层角色切换不触发 GeoJSON 重新解析。
- 路径缓存按边界内容、投影与缩放变化更新，不因极光动画失效。
- 极光动画只重绘悬浮球自身，不触发整张地图重组或重绘。
- 快速点击和动画取消不得累积协程、监听器或地图回调。

## 9. 测试设计

### 9.1 单元测试

- `ViewportState`：竖屏、横屏、不同安全边距和极端宽高区域的镜头目标。
- `MapController`：650ms 目标动画、取消旧动画、仅最新请求完成。
- `MapViewModel`：`Idle → Animating → Focused`，快速连续选择、缺少边界回退、取消后不弹旧卡片。
- 图层状态：全国层级省界为 `ACTIVE`；钻取后省界为 `CONTEXT`，子区域为 `ACTIVE`。
- 命中测试：上下文层不可点击，当前层可点击。
- 子区域加载失败：不提交新路径，不清空现有地图。

### 9.2 Compose UI 测试

- 默认 HUD 显示标题、点亮进度和层级信息。
- 区域卡片只在聚焦完成后出现。
- 悬浮球保留“当前定位”和“地图工具”语义。
- 工具菜单展开后主悬浮球动画进入暂停状态。
- 大字体下工具菜单内容完整可见。

### 9.3 Android 模拟器验收

按项目规则执行：

1. 修改前截取主页基线截图。
2. `./gradlew installDebug` 构建并安装。
3. 启动应用，使用 `adb shell input tap/swipe` 和 `adb shell monkey` 复现真实交互。
4. 录屏验证单击、高亮、650ms 居中放大、卡片延后出现。
5. 分别选择面积大、面积小、靠近地图边缘的省份。
6. 快速连续点击两个省份，确认只出现最后一个区域的卡片。
7. 进入市级、返回省级、回到全国，确认上下文层持续存在。
8. 验证江苏等历史上可能延迟加载的区域不会出现无反馈空白画布。
9. 截取修改后截图并保留录屏；如果目标设备不支持 `screenrecord`，则保留带时间顺序的交互截图组并在验收记录中注明。

### 9.4 iOS 模拟器验收

- 在 iPhone 模拟器中验证相同的主页配色、HUD 层级和底部安全区。
- 验证单击聚焦、快速切换、进入市级和返回全国。
- 验证极光悬浮球的动画范围、点击命中和菜单展开暂停。
- 保存至少一组主页和区域聚焦后的截图。

## 10. 完成标准

- 默认主页肉眼可见地采用晨雾青瓷方向，地图仍是第一视觉主体。
- 单击区域无需双击或额外按钮即可完成高亮、居中和放大。
- 区域卡片只在镜头稳定后出现。
- 钻取到市或区后，全国上下文仍清晰但不抢眼，且不会误触。
- 子区域延迟或失败时不出现无反馈空白地图。
- 极光悬浮球持续运动时克制、菜单展开时暂停、减少动态效果时静止。
- 自动化测试通过，Android 和 iOS 均有真实运行截图；Android 额外有录屏。目标设备不支持 `screenrecord` 时，使用带时间顺序的交互截图组并注明原因。
