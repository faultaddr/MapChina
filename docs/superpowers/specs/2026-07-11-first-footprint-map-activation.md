# 首次足迹地图内激活设计

## 目标

让零足迹用户在首页地图内完成第一处点亮，不再先阅读全屏说明，也不把用户导离地图核心体验。

## 状态模型

首次激活状态由当前用户是否存在地区足迹或景点到访记录实时决定，不再依赖“引导展示次数”。

1. **待激活**：地图正常可操作，右下角工具球附带“添加第一处足迹”标签。
2. **选择入口**：展开后仅展示“在地图上选择”“搜索景点”“使用当前位置”。
3. **地图选择中**：工具球标签改为“轻点地图选择”，点击地区后立即打开停留级别选择。
4. **确认停留级别**：地区面板直接展示“途经 / 小驻 / 深游”，不再先点击“标记足迹”。
5. **点亮成功**：关闭地区面板，对目标地区做一次有限晕染，HUD 进度更新，并显示轻量成功条；结束后恢复普通地图工具球。

## 三个入口

### 在地图上选择

- 进入选择态后收起菜单。
- 用户点击任意可选地区时，地图保持当前层级并弹出地区面板。
- 首次激活时地区面板隐藏普通操作矩阵，直接询问“这次停留有多深？”并展示三个级别。

### 搜索景点

- 进入现有景点探索页，并自动聚焦搜索框。
- 景点详情中的到访标记沿用现有能力；返回地图后，零足迹状态必须按仓储真实数据重新计算。

### 使用当前位置

- 获取当前位置并匹配到最具体的区县、城市或省份。
- 地图移动到匹配地区，同时打开首次停留级别面板。
- 定位不可用时使用现有轻提示反馈，不写入足迹。

## 成功反馈

- 地区填色立即切换到对应足迹颜色。
- 目标地区做一次 1.2 秒左右的有限呼吸晕染，不循环。
- 成功条文案为“第一处已点亮”，副文案使用“地区名 · 停留级别”。
- 成功条不与地区面板、足迹建议或工具菜单同时出现，约 2.2 秒后自动消失。
- HUD、地区填色和成功条在点击后乐观更新，后台持久化结束后与仓储真实状态对账；失败时完整回滚并提示重试。

## 常规状态

- 用户已有任意足迹后，工具球恢复普通“地图工具”形态和完整菜单。
- 照片能力在常规菜单中改为“照片回溯 · 实验”，不进入首次激活主路径。
- 随机出发、分享、定位和回到全国保持现有行为。

## 移除项

- 删除旧四步全屏 `OnboardingOverlay`。
- 删除基于 `onboarding_shown_count` 的展示次数状态。
- 首次激活过程中不展示照片回溯、随机出发或分享。

## 验收

- 零足迹首页没有全屏说明，能看到“添加第一处足迹”。
- 首次工具菜单只有三个入口，地图选择后无需再点击“标记足迹”。
- 首次点亮后旧面板退出，地图有有限晕染，HUD 从 0 更新，成功条出现后自动收束。
- 已有足迹用户看到原有地图工具菜单，照片入口明确标记为实验。
- 1.0 与 1.5 字体下，标签、菜单、地区面板和成功条不与底部导航重叠。
