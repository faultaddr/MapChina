# 首页地图 UI 重构设计

## 目标

首页回到“足迹地图”本身：地图承担第一视觉，状态与操作只在需要时出现，不再用大卡片遮挡地图。

## 信息层级

1. 顶部 HUD 只回答“我在哪一层、点亮了多少”：当前地区、地图层级、已点亮数量和完成度。
2. 右下角悬浮球是唯一常驻操作入口；随机出发、照片、分享、定位和回到全国全部收进同一个工具菜单。
3. 足迹建议、地区详情和景点预览仍作为底部上下文面板，但出现时隐藏悬浮球，避免操作重叠。

## 视觉

- HUD 使用 8dp 圆角的半透明地图铭牌，不再使用大胶囊。
- 悬浮球使用 56dp 主按钮、细进度环和 8dp 圆角的向上展开菜单。
- 移除首页底部“地图操作”大卡；底部渐隐缩短，给地图更多有效画面。
- 地图主题定义自己的纹理强度、地区底色、标注色和浮层色。宣纸与水墨降低纹理强度，星夜改用浅色标注。
- 未点亮地区保持安静，省界清晰；到访色仍保留深游、小驻、途经的层级。

## 交互

- 点击悬浮球展开或收起工具菜单；点击空白地图收起。
- 菜单从悬浮球上方向上展开，不侵占底部导航，也不覆盖顶部 HUD。
- 全国态不展示“回到全国”；进入省、市、县层级后再提供该动作。
- 上下文面板出现时隐藏工具球；面板关闭后恢复。

## 验收

- 首页不再出现“地图操作”底部卡。
- 常驻界面只显示“地图工具”悬浮球；展开后才显示各动作。
- 1.0 与 1.5 字体下，HUD、菜单、底部上下文面板均不重叠导航栏。
- 宣纸与星夜至少各验证一次地图标注和浮层对比度。
