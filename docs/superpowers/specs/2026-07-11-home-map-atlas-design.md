# 首页地图「数字山河图鉴」设计规格

## 目标

让首页首先像一张可操作、可收藏的中国足迹图，而不是把地图当作多个悬浮组件的背景。地图负责建立情绪和空间认知，HUD 只保留必要进度，工具区负责高频操作，所有浮层遵守统一层级，并在 Android 与 iOS 上保持同等质量。

本轮只重构首页全国/下钻地图的视觉构图与地图工具体验，不改变足迹数据模型、地图下钻规则、分享、照片回溯或随机出发的业务能力。

## 当前问题

1. 全国视图的相机中心同时照顾南海九段线，导致大陆主体偏上，页面下半段留白过多。
2. 顶部 HUD 是独立白色卡片，视觉上脱离地图，且重复强调进度。
3. 工具球尺寸和阴影过重，外圈进度与 HUD 重复；首次足迹的文字卡和圆球又形成两个拼接组件。
4. 展开工具后每个选项都是一张独立小卡，层级碎、扫描成本高。
5. 定位藏在工具菜单末尾，高频操作需要两次点击。

## 视觉原则

- **地图是主角**：任何常驻 UI 都不能比中国轮廓更抢眼。
- **信息无卡片化**：标题、层级和进度作为地图铭牌直接落在画布上。
- **操作成组**：高频定位独立，低频功能收纳进一块工具面板。
- **状态不重复**：进度只在地图铭牌展示，工具按钮不再绘制进度圆环。
- **主题兼容**：经典、纸张、山水和深色主题共享布局，只替换主题颜色与纹理。

## 地图构图

### 全国视图

- 全国视图使用独立的“展示取景范围”，不再把南海最南端作为大陆主体的垂直中心。
- 相机展示范围以东经 73°–136°、北纬 15°–54°计算；地图数据、点击区域和全国边界约束仍保留完整经纬度范围。
- 南海九段线继续在同一地图画布绘制，位于大陆主体下方，不做装饰卡片或静态截图。
- 大陆轮廓保持完整，不通过横向裁切制造放大感；主要修正纵向中心和视觉重心。

### 下钻视图

- 省、市、区县继续使用现有边界取景和相机动画。
- 顶部铭牌随层级更新，返回上级在原位置完成，不新增面包屑卡片。
- 地图标记、地区晕染和景点头图标记保持现有层级。

### 默认地图质感

- 经典主题加入极低透明度的现有纸张纹理，避免纯色大面积留白，但不能呈现明显宣纸黄或仿古滤镜。
- 画布使用中性浅灰绿，未点亮地区接近白色，省界使用低饱和青绿，文字使用中性深灰绿。
- 已点亮颜色继续区分途经、小驻、深游；庆祝金色只用于瞬时反馈和进度线。
- 其他地图主题不改变其既有背景资源，只同步使用新的构图和控件结构。

## 顶部地图铭牌

用 `HomeMapTitle` 替换现有带背景、边框和阴影的 `HomeMapHud`。

### 全国层级

- 第一行：`中国`，22sp 粗体；右侧为 `1/34 已点亮`，13sp 强调色。
- 第二行：`省级地图 · 2%`，12sp 次级色；末尾接 88dp、3dp 高的细进度线。
- 直接绘制在顶部渐隐保护区，不使用 `Surface`、描边或投影。

### 下钻层级

- 返回按钮使用 40dp 圆形点击区域、20dp 图标，与当前地区名同一行。
- 当前地区名最长单行省略；进度信息保持右对齐。
- 点击返回保持现有中等触觉反馈。

## 地图工具 Dock

### 常规状态

- 右下角改为两枚纵向按钮：上方 `当前位置` 44dp，下方 `地图工具` 48dp，间距 8dp。
- 按钮使用主题表面色、1dp 低对比边界和 3dp 阴影；不再使用 54dp 实心强调色大圆球。
- 地图工具图标改为“调节/图层”语义，不继续使用容易被理解为导航的指南针。
- 定位可用时一次点击直接执行；定位失败继续复用现有轻提示。

### 展开状态

- 所有低频操作放进一块宽度 168–196dp 的纵向 `Surface`。
- 每行高度至少 46dp，图标 19dp，文字 13sp；行之间只使用间距或细分隔线，不拆成多张卡片。
- 菜单从工具按钮上方展开，使用 160–200ms 淡入与轻微上移；关闭时反向收束。
- 菜单外区域点击收起，地图不响应本次点击。
- 常规菜单保留：回到全国（仅下钻时）、随机出发、照片回溯 · 实验、分享。当前位置已独立，不在菜单中重复。

## 首次足迹操作

- 零足迹默认状态使用一枚 48dp 高的图标文字按钮：定位/足迹图标 + `添加第一处足迹`。
- 按钮作为单一整体，不再使用“文字卡 + 圆球”的拼接结构。
- 点击后仍展开已确认的三个入口：在地图上选择、搜索景点、使用当前位置。
- 地图选择态收起为 `轻点地图选择` 紧凑提示，高度 42dp，使用中性主题表面，不遮挡省份主体。
- 首次点亮成功条继续拥有最高层级；成功条结束后无跳动地切换到常规两按钮 Dock。

## 浮层层级与位置

从低到高固定为：

1. 地图画布、主题纹理、地区与标记。
2. 顶部地图铭牌、常规工具 Dock。
3. 工具菜单及其透明点击拦截层。
4. 足迹建议、地区面板、景点预览和照片预览。
5. 首次足迹成功条、成就提示、分享与随机出发全屏状态。

所有底部浮层统一基于 `LocalScaffoldBottomPadding` 定位：Dock 距底部导航内容区 16dp；地区面板和成功条距内容区 8–14dp。任一底部面板出现时隐藏 Dock，避免功能和视觉重叠。

## 动效与触觉

- Dock 菜单展开/收起使用 160–200ms，不做弹簧过冲。
- 地图相机只在返回全国、下钻和定位时移动；打开工具菜单不改变地图。
- 定位和打开工具使用中等触觉，菜单项使用轻触觉，首次点亮继续使用成功触觉。
- 全国地图首次布局不播放缩放动画，避免启动时地图跳一下。

## 可访问性与响应式

- 所有图标按钮点击区域至少 44dp。
- 1.5 字体下，地图铭牌允许第二行扩展，但不能覆盖中国轮廓或状态栏。
- 菜单宽度允许随最长文案增长到 196dp；文案不缩放、不截断核心动作词。
- 深色主题下控件表面、文字和边界必须达到清晰对比，图标不能沿用白底固定颜色。
- 工具按钮保留明确的 `contentDescription`，菜单每行使用可读文字语义。

## 测试与设备验证

### 自动化

- 全国展示取景中心不再由北纬 3°决定，南海数据仍保持可投影。
- 常规状态只显示独立定位和地图工具按钮，菜单内不重复当前位置。
- 首次状态只显示单一图标文字按钮，三个入口能力不变。
- 地图铭牌没有卡片语义，层级和进度文案在零足迹、已有足迹和下钻状态正确。

### 双端功能矩阵

本轮及后续 UI/UE 迭代不能再以共享 Compose 代码作为 iOS 正确性的替代证据。Android 与 iOS 都要真实启动并覆盖：

- 启动页、四个底部 Tab、安全区和系统返回行为。
- 足迹首页的零足迹、三个激活入口、地图选区、定位、停留级别、成功态、常规 Dock、下钻和返回全国。
- 发现页的今日推荐、推荐列表、头图到详情的连续转场和返回路径。
- 题刻入口、新建题刻、真实背景和大字榜书效果。
- 山河与我的页面的首屏加载，以及图鉴、日志、成就等可达入口的基础冒烟。
- 平台权限不可用或用户拒绝时的现有降级反馈，不允许崩溃或静默替代。

### Android / Pixel 9 Pro

- 安装并启动应用，分别截取零足迹、已有足迹、工具菜单、下钻、地区面板和成功态。
- 对比改造前后全国地图主体的垂直位置、HUD 视觉重量和底部操作占用。
- 在 1.0 与 1.5 字体下验证铭牌、菜单、首次按钮和地区面板；最后恢复 1.0。
- 使用 ADB 点击定位、菜单、返回全国和地区选择，确认无点击穿透、无浮层重叠、无崩溃日志。

### iOS / iPhone 17 Pro Simulator

- 使用 Xcode 26.2 构建 `iosApp`，安装并启动到 iPhone 17 Pro、iOS 26.2 模拟器。
- 终端使用 `simctl` 完成应用重置、照片/定位权限、上海模拟定位、截图、Dynamic Type、明暗外观和进程日志。
- Simulator 内使用 Computer Use 完成点击、滚动、地图选择、底部 Tab、详情返回和边缘返回手势，不能只看启动截图。
- 对照 Android 的同一功能矩阵逐项截取证据；允许平台系统控件外观不同，但信息层级、功能可达性、状态反馈和安全区必须一致。
- Dynamic Type 使用 `extra-extra-extra-large`，验证后恢复 `large`；同时检查深色外观下文字、按钮和地图边界对比度。

## 不在本轮范围

- 不新增地图主题选择入口。
- 不重做省市区边界数据或标签碰撞算法。
- 不改变发现页、山河页和个人页结构。
- 不把照片回溯从实验状态升级为正式能力。
